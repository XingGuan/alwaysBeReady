#### `H5`如何解决软键盘弹起挡住输入框  
解决软键盘遮挡输入框的核心思路就一句话：**当键盘弹起、可视区域变小时，主动把输入框挪到可视区域内**。   
具体实现上，就是两大类：  
1.滚动方案:把输入框"滚"进可视窗口  
通过调整页面的滚动位置，让输入框出现在当前可见范围。   
+ `scrollIntoView()`  
最简单，让浏览器自动计算并滚动。  
```javascript
inputEl.scrollIntoView({block:'center',behavior:'smooth'});
```  
适合**页面整体可滚动**的场景（如长表单）。   
+ 手动控制`scrollTop`/`window.scrollTo()`  
更精细地控制滚动距离，比如配合`getBoundingClientRect()`和`visualViewport.height`算出精确偏移。   
```javascript
const rect = inputEl.getBoundingClientRect();  
if(rect.bottom > window.visualViewport.height){
    window.scrollBy(0,rect.bottom - window.visualViewport.height + 20);
}
```  
+ `rect.bottom`:输入框**底部边缘**距离**可视窗口顶部**的距离（单位`px`）。  
+ `visualViewport.height`: 当前可视窗口的总高度。   
`window.scroll(0,y)`的含义：  
+ `y`为正值：视口下移，相当于页面内容向上移动，可以看到更靠下的内容。  
+ `y`为负值：视口上移，页面内容向下移动，能看到更靠上的内容。

**优点**：不会改动布局，侵入性小。  
**局限**：要求页面必须有滚动空间（内容高度》键盘压缩后的视口高度），且对`fixed`定位的输入框无效。   

2.布局调整方案：改变输入框的"位置"或"高度"  
让输入框跟随可视区域的变化而动态位移，通常是修改`bottom`、`height`或容器的位置。   
+ 动态`bottom`值（针对`fixed`输入框）
键盘弹起时，给固定底部的输入框加上键盘高度的`bottom`偏移，让它"浮"在键盘上方。   
```javascript
const keyboardHeight = window.innerHeight - visualViewport.height;
inputBar.style.bottom = keyboardHeight + 'px';
```  
适合**聊天底部输入框**等必须吸附底部的场景。   
+ **用正常文档流+`Flex`布局替代`fixed`**(**推荐**)  
让输入框自然跟随页面内容，键盘弹起时布局视口缩小，输入框自动被"推"上来。这是从根本上避免固定定位和键盘冲突的最佳方案。  
结构：`body`为`flex`列，内容区`flex:1;overflow-y:auto;`,输入框在底部且不固定。   
+ **动态修改容器高度**  
用`JS`实时设置页面容器高度为`visualViewport.height`,取代不稳定的`100vh`，使布局完全适应键盘变化。  
**优点：能处理`fixed`定位和无法滚动的页面**。  
**局限：需要改布局结构，可能影响其他元素**。  

|场景|推荐方案|
|---|---|
|长表单，内容自然可滚动|滚动方案（`scrollIntoView`），成本最低|
|聊天/评论等底部固定输入框|首选`flex`布局+动态高度；次选动态`bottom`|
|需要适配奇葩机型/输入法|结合`visualViewport`事件，两种方案混用并精细计算|  

#### 最终实践：一条完整的“防御线”  
通常不是只挑一种，而是组合使用：  
1.布局层：优先用`flex`文档流，避免`position:fixed;bottom:0`
2.监听层：利用`visualViewport.resize`精确感知键盘变化。  
3.动作层：计算键盘高度，动态调整输入框位置；同时对于可滚动的区域，可以再调用`scrollIntoView`作为双保险。
